## [0.1.0]

### Added

- Diagram, split and text views for `.bpmn`, `.bpmn2` and `*.bpmn20.xml` files, powered by bpmn-js
- Two-way sync between the diagram and the XML, with diagram edits as regular IDE undo steps
- Properties panel for names, IDs, conditions and documentation
- Selecting an element in split view moves the caret to its XML
- Light and dark theme support
- Export as SVG
- File | New | BPMN Diagram
